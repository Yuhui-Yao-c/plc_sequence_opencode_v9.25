候选池 · sequence_candidates.csv 三种格式，同一个原理

sequence_candidates.csv （每行 = 一条候选迁移）
ST01::Action1 | S=110 → S=120 | ST_CASE
EM04::Trans | S=100 → S=135 | PLCOPEN_EN
EM04::Trans | S=100 → NOT(S=100) | STATE_EXIT
EM07::Path | Step=10 → Step=20 | SMC2_RUNG
每行字段：构成要素 · 开始标签 · 结束标签 · 来源标记
开始/结束就是状态等式；来源标记只记录证据，不影响采集
① PLCopen

MOVE 块 EN 回溯到 EQ 比较块

② omron ST

CASE 分支号 = 当前状态

③ SMC2

Rung 路径回溯使能条件

三种格式回答同一个问题："谁触发了状态赋值" → 触发条件 + 赋值目标 = 候选迁移

边界规范化 · 标签怎么变 区域首出口 BFS

规范化前（复合标签）

开始: S=100
结束: NOT(S=100 OR S=120)

源图: 100 → 120 → 135 → 180

含 OR/AND/NOT 复合式

规范化后（单状态等式）

开始: S=100
结束: S=135

# 到120时原终点尚不成立（120在集合内）
# 到135首次离开集合 → 取135
# 不跨过出口找更远的180

单状态等式，不含 AND/OR/NOT

更多变形规则

原始结束标签规范化后说明
NOT(S=100)查源图 100→135单状态退出
NOT(S=100 OR S=200)，起点 100/200100→? · 200→? 各一行OR 分支分行（不做笛卡尔积）
S=100 AND Ready待核验无别名证据，不删 AND
S=100 AND Arrived委托 FeedbackResolver → S=110反馈直接后继，标"条件替代"

合并语义：动作 A→B 紧接无新动作的信号/数据处理 B→C → 采集区间 A→C。新的计时区间，不是边界等价。

工位命名优先级

0. POU 路径直提 → 1. station_identity → 2. SC04 中文后缀 → 3. var_docs → 4. 裸 code

数组型状态机（m_nNextAutoStep[N]）每个下标独立身份。包mylar 从 1 个工位组 → 20 个（EM01_物流线 … EM20_治具回流）。

动作描述 · A 档优先源码步注释 人工表 97.7% 逐字来自源码 //注释

源码 ST 代码里的步注释

abEM08ActionStart[3] := ST01.AutoStep[2]=210;
                                //Z轴下降到取料位
abEM08ActionStart[4] := ST01.AutoStep[2]=220;
                                //电夹爪放料

extract_step_comments 提取为：

{
  "ST01.AutoStep[2]=210": "Z轴下降到取料位",
  "ST01.AutoStep[2]=220": "电夹爪放料"
}

三格式通用：PLCopen <STCode> · omron CASE · omron FBD 返回空

A 档优先级（cmd_a）

  1. step_comments.json[start_label] → 纯中文步注释
  2. CSV 动作描述列（codesys 步注释，过滤模板）
  3. 留空（不 fallback 到变量翻译）→ 交 B 档
变量翻译不进描述列（含英文），只进"动作变量引用"列

B 档 LLM 补充

A 档为空的行 → cmd_build 生成批次 → agent 写 result → cmd_validate 合并 B+A

注入变量文档 + step_comment 上下文 + "一行一动作重点"

白名单①

refs⊆tokens：引用变量必须在该行动作变量内

白名单②

无英文标识符：≥2字符 ASCII 标识符则拒

白名单③

中文词命中白名单：verbs+members+通用机构词

每列怎么来的

  • 构成要素 ← station_identity + SC04 后缀
  • 动作描述 ← A 档步注释 + B 档 LLM（过白名单三闸）
  • 时长 ← trace_step_runtime.csv（无 trace 则空）
  • 动作变量 ← plcopen_action_trace 等
  • 标签 ← final_prediction_pairs.csv
  • 备注 ← network_comments.json + 待复核标记

样式

  • 工位列纵向合并，块尾"总时长"行
  • 统一 Arial 9，行高 18
  • 待复核：备注列红色加粗【待复核】
  • 排序：EM/ST 数值序（EM01<...<EM10）
  • 排序仅为展示，不代表执行顺序
