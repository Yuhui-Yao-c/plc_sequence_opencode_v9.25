strict=True · InlineST 尾段

不可证语句 整段阻断（抛 WireError）

  • 函数调用 → WireError
  • 无参语句 → WireError
  • 字符串赋值 → WireError
  • 表达式 RHS → WireError
  • RETURN → WireError
  • FOR/WHILE/REPEAT/JMP → WireError
为什么：守护 signal_tail_merge 的零副作用前提，由测试锁定

  • st_call_may_write_state（函数调用）

# AND 并集 / OR 交集（不是同网络共现）
def required_signals(x):
    if x.kind=='and':
        return set().union(*(required_signals(a)
                              for a in x.args))
    if x.kind=='or':
        return set.intersection(*[required_signals(a)
                                 for a in x.args])
